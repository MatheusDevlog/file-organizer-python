# 📂 File Organizer in Python

Organizador de arquivos desenvolvido em Python que permite organizar arquivos de um diretório de forma automática, utilizando uma interface gráfica simples para seleção da pasta.

## 🚀 Funcionalidades
- Organiza arquivos por tipo (extensão)
- Organiza arquivos por data de modificação
- Criação automática de pastas
- Proteção contra sobrescrita de arquivos com o mesmo nome
- Interface gráfica simples usando Tkinter

## 🛠 Tecnologias utilizadas
- Python 3
- Tkinter
- OS
- Shutil
- Datetime

## 📦 Como executar
1. Clone o repositório:
```bash
git clone https://github.com/MatheusDevlog/file-organizer-python.git
```

2. Execute o arquivo:
```bash
python organizer.py
```
